# 🚀 TaskFlow - Modern Todo App

A modern and responsive Todo application built with **HTML**, **CSS**, **Bootstrap**, and **Vanilla JavaScript**. The application helps users manage daily tasks efficiently with a clean UI and persistent local storage.

## 🌐 Live Demo

👉 https://mostafamohamid.github.io/Todolist/

## ✨ Features

- ✅ Add new tasks
- ✅ Mark tasks as completed
- ✅ Delete tasks
- ✅ Search tasks instantly
- ✅ Filter by:
  - All Tasks
  - Completed
  - Pending
- ✅ Local Storage support
- ✅ Responsive Design
- ✅ Modern Glassmorphism UI
- ✅ Dashboard Statistics
  - Total Tasks
  - Completed Tasks
  - Pending Tasks

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/MostafaMohamid/Todolist.git
```

Open the project folder

```bash
cd Todolist
```

Run the project by opening:

```text
index.html
```

No installation or build tools are required.
